# Contributing

Thank you for improving Smart School Scheduling.

1. Fork and create a feature branch from the default branch.
2. Follow CodeIgniter 4 conventions (Query Builder, Filters, migrations for schema changes).
3. Run tests: `vendor/bin/phpunit` (MySQL test DB optional for unit tests).
4. Keep commits focused; describe **why** in the message.

Consult `docs/PRD.md` for scheduling constraints (HC/SC) before changing the solver.
